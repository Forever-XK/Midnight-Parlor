# 庭院小憩 · 斗地主

![Version](https://img.shields.io/badge/version-2.0.0-8A2BE2) ![License](https://img.shields.io/badge/license-MPL--2.0-blue)

一款前后端分离的网页斗地主游戏，支持六种玩法、三档 AI、好友联机和个性化外观。V2.0.0 重构庭院主题界面，升级发牌与出牌动画，加入更多牌面、更多语音、更多特效与排行榜，欢迎体验交流。

完整版本变更见 [CHANGELOG.md](./CHANGELOG.md)，游戏首页见「更新日志」。

## 游戏玩法

| 模式    | 规则与流程                                |
| ----- | ------------------------------------ |
| 经典斗地主 | 叫分确定地主，逐张乱序发牌后理牌。                    |
| 不洗牌   | 牌型更集中，按 4+4+4+5 分批发牌后理牌。             |
| 癞子    | 发牌前抽取癞子，支持百搭与多种牌型解释。                 |
| 癞子不洗牌 | 单癞子规则结合分批发牌，牌型聚集程度介于经典与不洗牌之间。        |
| 天地癞子  | 发牌前抽天癞子，确定地主后抽地癞子，支持多张炸弹比较。          |
| 闷抓斗地主 | 发牌前展示明牌；持有者可闷抓或不叫，不叫后展示翻牌动画，再进入后续叫分。 |

地主先出牌，任一阵营的玩家率先出完手牌即判定该阵营获胜。

## 功能

- **对战**：休闲、标准、高手三档 AI；支持创建房间邀请朋友，空座位由 AI 补齐，使用 WebSocket 同步。
- **对局表现**：叫分结果、地主皇冠、底牌翻面飞入手牌、乱序发牌与理牌、出牌提起落桌；顺子、连对、飞机及炸弹、王炸专属特效。
- **结算**：炸弹与王炸特效后提示 ×2，春天与反春天动画、阵营胜利动画；先在原出牌区依次亮出剩余手牌，再显示结算面板。
- **个性化**：实时预览并切换牌面、牌背、背景、音乐、语音与特效。
- **音画资源**：青青草原背景，普通话 / 台湾腔与男声 / 女声，四套背景音乐；透明 WebM 炸弹和王炸特效沿用游戏音效。
- **战绩与排行榜**：展示所有已保存昵称玩家的对局数、胜利局数、胜率，三项均可升降序排序；支持刷新和当前玩家标记，统计已完成的单机与联机对局，零场次玩家也会上榜。
- **操作与适配**：滑动多选、选牌音效、提前选牌、快捷语音、界面缩放、手机横置布局及再开一局。

用户目前按昵称区分，没有密码注册或账号登录。同昵称共用服务端战绩；修改昵称会使用对应昵称的档案。AI 不计入排行榜，旧版未统计的联机战绩无法追溯补录。

## 本地运行

本次构建验证环境：Node.js 24.11.1、npm 11.18.0。项目使用 npm 和仓库中的锁文件安装依赖。

在项目根目录执行：

```sh
npm ci
npm run dev
```

浏览器打开 `http://localhost:5173`。前端默认端口 5173，后端默认端口 3001；前端通过代理访问后端。

代码与所需图片、字体、音频、透明视频均位于本仓库。正常构建无需同级的 DPH、University 或 New 原始素材目录，也无需视频处理工具。

## 构建与部署

```sh
npm run build
npm start
```

打开 `http://localhost:3001`。后端提供 `dist/` 中的前端页面，并挂载 `/api` 与 `/ws`。`dist/` 不提交到 Git，每次部署先构建；`npm start` 只启动服务，不执行构建。

供局域网访问时，Windows PowerShell 使用：

```powershell
npm run build
$env:HOST = '0.0.0.0'
$env:NODE_ENV = 'production'
npm start
```

Linux / macOS 可使用 `npm run deploy`。客户端通过服务器地址和端口访问；反向代理需要转发 `/api`，并支持 `/ws` 的 WebSocket 连接。

| 环境变量           | 用途                               |
| -------------- | -------------------------------- |
| `PORT`         | 服务端端口，默认 3001。                   |
| `HOST`         | 本地开发默认 127.0.0.1，生产环境默认 0.0.0.0。 |
| `NODE_ENV`     | 设为 `production` 使用生产环境启动行为。      |
| `DDZ_DATA_DIR` | 可写战绩目录，源码运行默认 `api/data/`。       |
| `DDZ_DIST_DIR` | 前端构建目录，源码运行默认 `dist/`。           |

这些变量由启动进程的环境传入。

## Windows 桌面版

```sh
npm run desktop:build
```

产物为 `release/斗地主-v2.0.0-Portable.exe`，内嵌前端、后端与 Electron 运行时，用户无需安装 Node.js。战绩存放于 Electron 的系统用户数据目录，通常为 `%APPDATA%\ddz-game\`。安装包通过 GitHub Releases 单独分发，不提交到源码仓库。

## 项目结构

```text
api/              Express 接口、斗地主规则、AI、联机房间与战绩存储
src/              React 页面、动画组件、个性化设置与状态管理
shared/           前后端共享类型、玩法及排行榜排序逻辑
Sound/            运行所需语音、音效和音乐
public/           运行所需图片、字体与透明视频
electron/         桌面程序入口
package.json      运行、构建及桌面打包命令
package-lock.json 固定依赖版本
CHANGELOG.md      V2.0.0 更新记录
LICENSE           MPL-2.0 许可证
```

前端使用 React 18、TypeScript、Vite、Tailwind CSS、Zustand 与 Framer Motion；后端使用 Node.js、Express 与 ws；桌面端使用 Electron、electron-builder 与 esbuild。
